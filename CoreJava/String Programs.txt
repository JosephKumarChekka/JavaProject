{
	public static void main(String[] args) 
	{
		String s1 = "Raise12";
		String s2 = "Tech28";
		
		String word1  = s1.replaceAll("[^A-Za-z]","");  // Raise 
		int num1 = Integer.parseInt(s1.replaceAll("[^0-9]","")); // 12

		int num = num1 + num2;
		
		System.out.println(word+num);
	}	
}


Q) Write a java program to find out number of digits, sum of digits and check that number is even or odd?

Input:
	NEX123

Output:
	No of digits : 3
	Sum of digits : 6
	It is even number 
	

class Test 
{
	public static void main(String[] args) 
	{
		String str = "NEX123";
		
		String newStr = str.replaceAll("[^0-9]","");
		
		System.out.println("No of Digits : "+newStr.length());
		
		int sum = 0;
		for(char ch : newStr.toCharArray())
		{
			//convert character to number 
			int n = Character.getNumericValue(ch);
			sum += n;
		}
		System.out.println("Sum of Digits : "+sum);
		
		System.out.println((sum%2==0)?"It is even number":"It is odd number");
	}	
}
