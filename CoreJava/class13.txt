System.out.println()
====================
It is a output statement in java.

Whenever we want to display any data, expression or userdefined statements then we need to use output stmt in java.

syntax:
------		
	static variable 
		|
	System.out.println()
	|		|
	predefined 	predefined method 
	final class

Diagram: class13.1

ex:
---
class Test
{
	void main()
	{
		System.out.print("RAISE");
		System.out.print("TECH");
	}
}
o/p:
	RAISETECH

Various ways to display the data 
--------------------------------
1) custom message
   ex:
	System.out.println("Hello World")


2) int i = 10;
   ex:
	System.out.println(i);
	System.out.println("The value is ="+i)
	System.out.println(i+" is a value");
	System.out.println(" Before "+i+" After ");

3) int i=10,j=20;
   ex:
	System.out.println(i+" "+j);
	System.out.println(i+" and "+j); 

4) int i=1,j=2,k=3;
   ex:
	System.out.println(i+" "+j+" "+k);
