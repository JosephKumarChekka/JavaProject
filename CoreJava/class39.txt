Wrapper classes
===============
The main objective of wrapper classes are

1) To wrap primitive to wrapper object and vice versa.

2) To defined several utility methods.

ex:
	Primitive Type		Wrapper object	
	---------------		---------------
	byte			Byte
	short			Short
	int			Integer
	long			Long
	float			Float
	double 			Double
	boolean 		Boolean 
	char 			Character 

constructor 
----------
Every wrapper class contains two constructors. One will take corresponding primitive as an argument and another takes corresponding string as an argument.

ex:
	Wrapper class		Constructor
	-------------		-----------
	Byte			byte or String 
	Short			short or String 
	Integer			int or String 
	Long			long or String 
	Float			float or String 
	Double 			double or String 
	Boolean 		boolean or String 
	Character 		char 

ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		Integer i1 = Integer.valueOf(10);
		System.out.println(i1);
		
		Integer i2 = Integer.valueOf("20");
		System.out.println(i2);
	}
}

ex:
--
class Test  
{
	public static void main(String[] args) 
	{
		Boolean b1 = Boolean.valueOf(true);
		System.out.println(b1);
		
		Boolean b2 = Boolean.valueOf("false");
		System.out.println(b2);
	}
}

ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		Character c = Character.valueOf('a');
		System.out.println(c);
	}
}

Utility Methods
===============

1) valueOf() 
------------
It is used to convert primitive type or String type to wrapper object.

ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		//primitive type 
		int a = 10;
		
		//wrapper object 
		Integer i = Integer.valueOf(a);
		
		System.out.println(i);
	}
}

ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		//String type 
		String str="100";
		
		//wrapper object 
		Integer i = Integer.valueOf(str);
		
		System.out.println(i);
	}
}


2) xxxValue() 
--------------
It is used to convert wrapper object to primitive type.

ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		//wrapper object 
		Integer i = Integer.valueOf(20);
		
		//primitive type 
		byte b = i.byteValue();
		System.out.println(b); 
		
		short s = i.shortValue();
		System.out.println(s); 
		
		int a = i.intValue();
		System.out.println(a);
		
		float f = i.floatValue();
		System.out.println(f);
	}
}


3) parseXxx() 
-------------
It is used to convert string type to primitive type or wrapper object.

ex:
--
class Test  
{
	public static void main(String[] args) 
	{
		//String type 
		String str = "56";
		
		//primitive type 
		int i = Integer.parseInt(str);
		System.out.println(i); 
		
		long l = Long.parseLong(str);
		System.out.println(l);
		
		float f = Float.parseFloat(str);
		System.out.println(f);
	}
}


4) toString()
------------
It is used to convert Wrapper object or primitive type to String type.

ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		//wrapper object
		Integer i = Integer.valueOf(10);
		
		//string type 
		String s = i.toString();
		System.out.println(s); 
	}
}

ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		//primitive type 
		int i = 100;
		
		//string type 
		String s = Integer.toString(i); 
		
		System.out.println(s);
	}
}

Interview Questions 
===================

Q) Write a java program to perform sum of two binary numbers?

input:
	1010
	0101
output:
	1111

import java.util.Scanner;
class Test  
{
	public static void main(String[] args) 
	{
		Scanner sc = new Scanner(System.in);
		System.out.println("Enter the first binary number : ");
		String binary1 = sc.next();
		System.out.println("Enter the second binary number : ");
		String binary2 = sc.next();
		
		//convert binary number to decimal number 
		int a = Integer.parseInt(binary1,2);
		int b = Integer.parseInt(binary2,2);
		
		int c = a + b;
		
		//convert decimal number to binary number 
		String result = Integer.toBinaryString(c);
		System.out.println(result);
	}
}


Q) What is the difference between Autoboxing and Autounboxing in java?

Autoboxing 
==========
Automatic conversion from primitive type to corresponding wrapper object performed by the compiler is called autoboxing.

Autoboxing internally uses valueOf() method.

ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		//primitive type 
		int a = 10;
		
		//Wrapper object 
		Integer i = a;
		
		System.out.println(i);
	}
}

Autounboxing 
==========
Automatic conversion from wrapper object to corresponding primitive type performed by the compiler is called autounboxing.

Autounboxing internally uses xxxValue() method.
	
ex:
---
class Test  
{
	public static void main(String[] args) 
	{
		//wrapper object
		Integer i = Integer.valueOf(10);
		
		//primitive type 
		int a = i;
		
		System.out.println(a);
	}
}

Inner classes
=============
Somtime we will declare a class inside another class such concept is called inner class.

syntax:
	class Outer_class
	{
		class Inner_class
		{
			-
			-	
		}
	}

Inner class introduced in 1.1 version as a part of event handling to remove GUI bugs.

But due to powerful features and benefits of inner classes. Programmers started to use innter classes in regular programming.

Inner classes does not allow static members.

We have four types of inner classes in java.

1) Normal/Regular Inner class

2) Static inner class

3) Method Local inner class

4) Anonymous inner class 

1) Normal/Regular Inner class
-----------------------------
If we declare a class inside another class such concept is called normal/regular inner class.

Inner class must declare within the scope of enclosing class.

ex:
---
class Outer 
{
	class Inner 
	{
		public void methodOne()
		{
			System.out.println("Inner-methodOne");
		}
	}
	
	public static void main(String[] args)
	{
		Outer.Inner i = new Outer().new Inner();
		i.methodOne();
		
		//or
		
		new Outer().new Inner().methodOne();
	}
}
If we compile above program we will get two .class files i.e Outer.class and Outer$Inner.class.


2) Static inner class
--------------------
Sometimes we will declare a class inside another class by using static keyword such concept is called static inner class.

In regular/normal inner class, without existing container object there is no chance of having contained object.

ex:
---
class Outer 
{
	static class Inner 
	{
		public void methodOne()
		{
			System.out.println("Inner-methodOne");
		}
	}
	
	public static void main(String[] args)
	{
		Inner i = new Inner();
		i.methodOne();
	}
}

3) Method Local inner class
---------------------------
Sometimes we will declare a class inside a method such concept is called method local inner class.

The main objective of method local inner class is to execute method specific repeated logic.

ex:
--
class Outer 
{
	public void m1()
	{
		class Inner 
		{
			public void sum(int a,int b)
			{
				System.out.println(a+b);
			}
		}
		Inner i = new Inner();
		i.sum(1,2);
		i.sum(10,20);
		i.sum(100,200);
	}
	
	public static void main(String[] args)
	{
		Outer o = new Outer();
		o.m1();
	}
}

4) Anonymous inner class
------------------------
Sometimes we will declare a class without name such type of name less class is called anonymous inner class.

ex:
---
interface ATM 
{
	public abstract void deposit();
}
class Test 
{
	public static void main(String[] args)
	{
		//anonymous inner class
		ATM atm = new ATM()
		{
			public void deposit()
			{
				System.out.println("Deposit Method");
			}
		};
		atm.deposit();
	}
}

ex:
---
abstract class Payment 
{
	public abstract void paymentMethod();
}
class Test 
{
	public static void main(String[] args)
	{
		//anonymous inner class
		Payment p = new Payment()
		{
			public void paymentMethod()
			{
				System.out.println("UPI");
			}
		};
		p.paymentMethod();
	}
}
