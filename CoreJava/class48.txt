Various ways to read inputs in java
===================================
There are fours ways to read inputs in java.

1) Command Line Arguments

2) BufferedReader class

3) Console class 

4) Scanner class

1) Command Line Arguments
-------------------------
class Test 
{
	public static void main(String[] args) 
	{
		String name = args[0];
		System.out.println("Welcome :"+name);
	}
}
o/p:
	javac  Test.java
	java  Test  Alan

2) BufferedReader class
-----------------------
import java.io.*;
class Test 
{
	public static void main(String[] args)throws IOException
	{
		BufferedReader br = new BufferedReader(new InputStreamReader(System.in));
		System.out.println("Enter the Name :");
		String name = br.readLine();
		System.out.println("Welcome :"+name);
	}
}


3) Console class 
----------------
import java.io.*;
class Test

	{
		Console c = System.console();

}

4) Scanner class 
-----------------
import java.util.*;
class Test 
{
	public static void main(String[] args)
	{
		Scanner sc = new Scanner(System.in);
		System.out.println("Enter the id : ");
		int id = sc.nextInt();
		
		System.out.println("Enter the Name :");
		String name = sc.next();
		
		System.out.println("Enter the Salary : ");
		double salary = sc.nextDouble();
		
		System.out.println(id+" "+name+" "+salary);
	}
}


FileInputStream 
================
It is used to read stream of bytes from a file.

FileOutputStream 
=================
It is used to insert stream of bytes into a file.



Q) Write java program to copy the data from one file to another file?

input:
	source.txt 
	---------
	a
	ab
	abc
	abcd 

import java.io.*;
class Test 
{
	public static void main(String[] args)
	{
		try(
				FileInputStream fis = new FileInputStream("source.txt");
				FileOutputStream fos = new FileOutputStream("destination.txt");
			)
		{
			int byteReads;
			byte[] barr = new byte[50];
				
			while((byteReads=fis.read(barr))!=-1)
			{
				fos.write(barr,0,byteReads);
			}
			System.out.println("Data Copied");
		}
		catch(IOException ioe)
		{
			ioe.printStackTrace();
		}
	}
}


Serialization 
=============
The process of taking object data and storing in a file is called serialization.

Converting object state to file state is called serialization.

To perform serialization we required ObjectOutputStream and FileOutputStream.

We can perform serialization only for serialized objects.

To create serialized object our class must implements Serializable interface.

Serializable is a marker interface which does not have any methods and constants.

By using Serializable interface we will get some ability to do by JVM.

Diagram: class48.1

ex:

import java.io.*;
class Person implements Serializable
{
	int age;
	String name;
	Person(int age,String name)
	{
		this.age = age;
		this.name = name;
	}
	public String toString()
	{
		return age+" "+name;
	}
}
class Test 
{
	public static void main(String[] args)
	{
		Person p = new Person(34,"Alan");
		try(ObjectOutputStream ostream = 
			new ObjectOutputStream(new FileOutputStream("abc.ser"));)
		{
			ostream.writeObject(p);
			System.out.println("Serialization Done");
		}
		catch(IOException ioe)
		{
			ioe.printStackTrace();
		}
	}
}

Deserialization 
================
The process of taking the data from a file and representing an object is called deserialization.

Converting file state to object state is called deserialization.

To perform deserialization we required ObjectInputStream and FileInputStream.

We can perform deserialization only for serialized objects.

To create serialized objects our class must implements Serializable interface.

Serializable is a marker interface which does not have any methods and constants.

By using Serializable interface we will get some ability to do by JVM. 

Diagram: class48.2

ex:
---
import java.io.*;
class Person implements Serializable
{
	int age;
	String name;
	Person(int age,String name)
	{
		this.age = age;
		this.name = name;
	}
	public String toString()
	{
		return age+" "+name;
	}
}
class Test 
{
	public static void main(String[] args)
	{
		try(ObjectInputStream istream = 
			new ObjectInputStream(new FileInputStream("abc.ser"));)
		{
			Person p = (Person)istream.readObject();
			System.out.println(p);
		}
		catch(IOException | ClassNotFoundException e)
		{
			e.printStackTrace();
		}
	}
}


Singleton class 
===============
It is a design pattern which ensures that a class must have single instance.

A class which allows us to create only one object is called singleton class.

To create singleton class we required private constructor and static method.

The main purpose of singleton class is to control object creations, save some memory and maintain consistency accross the application.

ex:
---
import java.util.Date;
class Singleton 
{
	static Date date=null;
	private Singleton()
	{
		System.out.println("date object is created");
	}
	public static Date getInstance()
	{
		if(date==null)
		{
			date = new Date();
		}
		return date;
	}
}
class Test 
{
	public static void main(String[] args)
	{
		Date d1 = Singleton.getInstance();
		System.out.println(d1.hashCode());
		System.out.println(d1);
		
		Date d2 = Singleton.getInstance();
		System.out.println(d2.hashCode());
		System.out.println(d2);
	}
}
