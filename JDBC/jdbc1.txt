JDBC 
=====
As if now it is known as trademark.

But earlier it is known as Java Database Connectivity.

RAM is a temperory storage device or medium.

During the program execution our data will store in RAM.

Once the program execution completed we will loss the data.

To overcome this limitation we are making our application writing the data into file's or database software's.

File's and database software's are permanent storage device or medium. Where we can store our data permanently.

Persistence 
===========
The process of storing and managing the data for a long period of time is called persistence.


Important terminologies 
=======================

1) Persistence store
-------------------- 
	It is a place where we can store our data for a long period of time.
	ex:
		File's
		Database Software's.

2) Persistence data 
-------------------
	Data of a persistence store is called persistence data.
	ex:
		Records 
		Tables 

3) Persistence operation
------------------------
	Insert, Update, Delete, Select, and etc are called persistence operations.
	In realtime we will call persistence operation as CURD operation, CRUD operation 
	or SCUD operation.
	ex:
		C - create 		S - select 				
		U - update 		C - create 
		R - read 		U - update 
		D - delete 		D - delete 

4) Persistence logic 
---------------------
	A logic which is capable to perform persistence operations is called 
	persistence logic.
	ex:
		JDBC code 
		Hibernate code 
		Ibatis code 
		and etc.

5) Persistence technology 
-------------------------
	A technology which is used to develop persistence logic is called persistence 
	technology.
	ex:
		JDBC 
		Hibernate 
		Ibatis 
		and etc.


Q) What is JDBC ? 

JDBC is a persistence technology that is used to develop persistence logics having the capability to perform persistence operations on persistence data of a persistence store.


Limitations with File as a persistence store 
============================================
1) It stores limited amount of data.

2) There is no security.

3) Fetching the data with multiple conditions is not possible.

4) It does not show an application with relationships.

5) It does not allow us to apply constraints.

6) Updation and Deletion of data can't be done directly.

7) Merging and comparision of data can't be done easily.


Advantages of database as a persistence store 
=============================================
1) It stores unlimited amount of data.

2) There is a security.

3) It supports common query language.

4) Fetching the data with multiple conditions is possible.

5) It shows an application with relationships.

6) It allows us to apply constraints.

7) Updation and deletion of data can be done directly.

8) Merging and comparision of data can be done easily.

Every JDBC application is a two-tier application. Where java with JDBC code acts like a frontend/tier1/layer1 and database software acts like a backend/tier2/layer2.

Enduser is a non-technical person. He can't prepare and execute SQL query in database software. So he depend upon frontend developers having capability to do that work for them.

Diagram: jdbc1.1


JDBC Driver 
===========
JDBC driver acts like a bridge between java application and database software.

It is used to convert java instructions to database instructions and vice versa.

Diagram: jdbc1.2


ODBC Driver 
===========
ODBC stands for Open Database Connectivity.

VBScript, D2K, Perl and etc uses ODBC driver to locate and interact with database software.

Diagram: jdbc1.3


ODBC driver is developed in C language by taking the support of pointers. But java does not support pointers. To overcome this limitation Sun Micro System introduced JDBC driver exclusively.
